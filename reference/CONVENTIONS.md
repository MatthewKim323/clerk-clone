# Aurora implementation contract

App: Next.js App Router with React 19. The preview uses http://localhost:3781.

## Reference and branding

The source location exists only in each reference directory's .origin.json. Never name it in shipped code, identifiers, filenames, comments, metadata, or documentation. Copy the sanitized reference copy. Use Aurora as the brand. No em dashes. Assets use content addressed names under public/assets. Inline wordmarks use the Aurora mark; captured illustration backplates may still contain placeholder marks.

## Rendering and styling

This is a Next.js site with compiled Tailwind CSS, not a Framer site. Preserve the exact captured responsive rules from public/site.css, generated from reference/site/dom/external-base.css. Do not substitute Framer breakpoints. Its native media rules include 640, 768, 1024, and 1280px.

Main tokens: ink #131316, page #f7f7f8, white #ffffff, purple #6c47ff. Suisse is the primary typeface, Geist handles numerals, and Soehne Mono handles code. The captured cookie notice inherits Suisse despite its font-inter class. Inter is available for other UI. Font files are local.

Static sections are generated by scripts/build-reference.ts into components/sections/markup/*.json. Section.tsx renders each through a display:contents boundary. Do not hand-edit generated JSON. Add deterministic markup transformations to the generator when needed. Existing source attributes and SVG paths are retained. data-reference-path maps the markup to captured layout.json entries for box comparison. data-section identifies each homepage section.

Home supports ?only=<section>, including hero, customers, components, authentication, organizations, billing, integrations, and testimonials. The complete page adds header, footer, and controls.

## Component responsibilities

- ComponentDemos.tsx and component-demos.css own the component gallery only.
- Navigation.tsx, navigation.css and navigation/ own header navigation behavior.
- HomeMotion.tsx and home-motion.css own the hero, logo rotation, feature demos, and testimonials.
- PageControls.tsx and page-controls.css own clipboard, cookie preferences, and support.
- ComponentPages.tsx and component-pages.css own linked component pages and their source-driven tours.
- RouteInteractions.tsx and route-interactions.css own docs, pricing, billing, and blog controls.
- MarketingMotion.tsx and marketing-motion.css own linked marketing-page motion and the shared footer shader.
- PublicForms.tsx handles local preview form behavior. BrandMarks.tsx replaces inline wordmarks inserted by demos.
- app/ owns the document shell, homepage assembly, and route integration.

Client behaviors attach after hydration through scoped effects and clean up listeners, timers, observers, and animations. Exact values come from reference/site/motion/component-specs.md and transitions.json. Keep effects scoped to their owning components. Reduced motion disables decorative loops.

Linked route markup is generated by scripts/build-routes.ts. The captured currentSrc is pinned per viewport to preserve the reference image aspect ratios. Typography corrections in content/routes/corrections.json restore wrapping after rebranding. They apply to stable text hashes, not arbitrary document positions. Shared sanitization also removes embedded identifiers and redirects unconfigured social profile links to their platform roots.

## Verification

Run bun run typecheck, bun run build, 1to1 blackout . --strict, and 1to1 verify http://localhost:3781/ reference/site --diff. All page and section heights must equal the capture at 1440, 1024, 810, and 390. Pixel diffs and animation frames require visual inspection; a height PASS alone does not establish full visual fidelity. Collect both console errors and pageerror events. Never alter reference measurements to make a build pass.

## Optional local tooling

The runtime app uses only committed files. Capture, generation, and browser-verification scripts additionally require a local toolkit checkout at `tooling/1to1`, its dependencies, and the relevant private raw captures. The tooling directory is ignored by git. Final reports and motion specifications are committed; bulky image/video evidence, logs, and private capture metadata remain local.
